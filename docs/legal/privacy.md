# Privacy

By default, the CLI collects anonymous usage data, which includes:

- Unique user ID
- OS Name
- Node Version
- CLI Version
- Command (`stepci init`, `stepci run`, `stepci generate`)
- Environment (Local, Docker, CI/CD)

::: info
The usage analytics is disabled by default and can be enabled by setting `STEPCI_ENABLE_ANALYTICS` environment variable
:::
